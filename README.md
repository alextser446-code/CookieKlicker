# Cookie Clicker

A cozy cookie-clicking game made with Python and Pygame. Click cookies, collect rewards, unlock new designs, and try your luck at the spinning wheel.

## Features

- Click the cookie to earn cookies
- Buy upgrades and earn cookies automatically
- Collect Golden Cookies and treasure chests
- Unlock and choose different cookie designs
- Customize the background and sound
- Spin the wheel using Golden Cookies

## Controls

- **Left mouse button:** Click cookies and use buttons
- **Esc:** Open or close the pause menu
- **F11:** Switch between fullscreen and windowed mode

## Play

On Windows, download and double-click `CookieKlicker.exe`. Python does not need to be installed.

To run from source, install Pygame and start the game:

```bash
python -m pip install pygame
python CookieKlicker.py
